# 正式な転倒評価を進めるための元資料

2026-09-06：実データは存在しないことを確認したため、この資料依頼は今回の投稿準備の
前提から外す。以下は将来の実測検証用の参考として保存する。
現在は [シミュレーション比較](SIMULATED_FALL_P1.md) を進める。

現在の配列だけでは、下記の情報を確定できない。モデル推定や多数決で埋めず、元資料との対応で確認する。

| 必要な資料 | 確認する内容 | 現在できない評価 |
|---|---|---|
| 元のLiDAR CSVと前処理コード | チャンネル定義、単位、欠損表現、正規化・clip、scalerのfit対象 | 学習側だけで前処理した評価、実機の欠損・遮蔽モデル |
| 窓から元記録への対応表 | 記録ID、被験者ID、施設ID、開始・終了フレーム | 被験者独立・記録独立・施設別B3 |
| ラベル生成コードまたは定義書 | binaryの転倒率0.3とsubclassの集計ルール | 検証index 111の正解確定 |
| イベント注釈と時刻 | 転倒開始・終了、記録の欠落、観測時間 | 転倒イベントrecall、誤報イベント/時間 |
| センサー設置・走査仕様 | 走査面、高さ、角度、beam対応 | 高さ特徴を使う既存条件推定器との適合性確認 |

対応表の空テンプレートは `docs/window_provenance_template.csv`。
必ずしもこの形式へ変換する必要はなく、元資料が保存されている場所が分かれば対応を調べられる。
元の検証index 111は全体index 1066、復元された連続順のposition 821に相当する。

資料受領後は、元記録・被験者を先に分割してから、学習側のみでscalerをfitし、窓を生成する。
その後、ラベル定義を確認して診断用の隔離を解除できるか判断する。
施設別しきい値・観測条件によるしきい値・共通しきい値を同じ独立評価データで比較する。
